# Vendored PDF tooling

`scripts/generate_review_pdf.py`, `scripts/prisma_flow.py` and `assets/` are copied
unchanged from the synthscholar skill (`agent_skills/skills/synthscholar/`), so a PDF
generated by ml_service matches one the skill produces locally. Update them by copying
again from the skill; do not edit here. ml_service runs the script as a subprocess
(`core/synth_scholar/review_pdf.py`), with pandoc and Typst from the Docker image.
